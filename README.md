# Portafolio personal

**Autor:** Thiago André Coronel Rodas

## Descripción

Este proyecto consiste en el desarrollo de un portafolio personal como actividad académica de Programación de Sistemas Web.

El sitio presenta información personal, habilidades relacionadas con la tecnología, proyectos de práctica y una sección de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- SVG para las ilustraciones
- Git y GitHub para el control de versiones

## Estructura del proyecto

- `index.html`: estructura y contenido del sitio web.
- `styles.css`: estilos y diseño visual.
- `img/portafolio.svg`: ilustración del portafolio.
- `img/proyecto-web.svg`: ilustración del proyecto web.

## Cómo ejecutar el proyecto

Abrir el archivo `index.html` en un navegador web.
